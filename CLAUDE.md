# HRM Portal

Laravel (Worksuite-based) HR portal.

## Pages and UI

Every new or changed page follows [docs/PAGE_RULES.md](docs/PAGE_RULES.md): the AJAX page
flow (content swap, `data-swap-links`, `PageSwap.open / reload / submit`, side panels,
JSON saves) and the standard page UI (top-right buttons + Filters, auto-applying filters,
side panels for add/edit, phone width). The Recruitment module is the reference.
